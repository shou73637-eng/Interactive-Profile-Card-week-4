# Interactive Profile Card

Project React (Vite) yang menampilkan Header dan beberapa Kartu Profil.
Menggunakan komponen yang dapat dipakai ulang, props, dan state (`useState`)
untuk tombol Like.

## Cara Menjalankan Project

1. Clone repository ini
   ```bash
   git clone https://github.com/shou73637-eng/Interactive-Profile-Card-week-4.git
   cd profile-card
   ```
2. Install dependency
   ```bash
   npm install
   ```
3. Jalankan development server
   ```bash
   npm run dev
   ```
4. Buka alamat yang muncul di terminal (biasanya http://localhost:5173).
